# SLM
This repo has been created for the TRI AI Saturdays Small Language Model Project.
The project is to build a small language model that generates medical advice for patients, medical practitioners, and medical advisors.
The dataset is very small, with only 43 data points.
We did not use pretrained models like GPT-2, Llama, or other Hugging Face models.
As we have learned, small datasets result in overfitted  models. This was what we experienced.
